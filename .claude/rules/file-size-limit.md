# 文件行数限制

> 控制单文件复杂度，减少 token 消耗，提升可维护性。

> 参考来源: 个人/团队约定

---

## 行数上限

| 语言 | 上限 | 说明 |
|------|------|------|
| Java | 300 行 | Spring 分层清晰，超过说明职责过多 |
| TSX/JSX | 200 行 | 模板+逻辑 |
| Vue | 200 行 | 样式已抽到 assets/styles，模板+逻辑 |
| TS/JS | 300 行 | 工具类、服务类 |

## 超限时的处理

**新建文件时**：

- 预估超限则提前拆分，不要写完再拆

**修改现有文件时**：

- 不强制重构现有大文件
- 新增功能如果会导致超限，拆到新文件

## 拆分指引

| 语言 | 拆分方式 |
|------|------|
| Java | Service 拆分职责、提取 Helper/Converter 类 |
| TSX/JSX | 提取子组件、hooks、样式文件 |
| Vue | 提取子组件、composables、样式到 assets/styles |
| TS/JS | 提取工具函数、常量、类型到独立文件 |
